# Portfólio de Análise de Dados

## Visão geral

Este repositório foi criado como espaço para guardar estudos, projetos e materiais de análise de dados. No estado atual, ele funciona mais como uma base para portfólio futuro do que como uma coleção de projetos concluídos.

## Situação atual

O repositório possui apenas este README. Ainda não há projetos completos, conjuntos de dados, notebooks ou dashboards. Por isso, as ideias abaixo são propostas futuras, não análises já executadas.

## Objetivos

- centralizar estudos e projetos de análise de dados;
- documentar fontes, processos e conclusões de cada análise;
- apresentar trabalhos práticos à medida que forem desenvolvidos;
- evoluir conhecimentos em Python, SQL, Excel e Power BI.

## Tecnologias e ferramentas

Ferramentas planejadas para estudos e projetos futuros:

- Python e Pandas
- SQL
- Excel
- Power BI
- SQLite

A presença nesta lista não significa que todas as ferramentas já tenham sido utilizadas em um projeto concluído neste repositório.

## Ideias para projetos futuros

### Análise de vendas

Possível estudo com dados públicos ou sintéticos claramente identificados, cobrindo limpeza, análise exploratória, indicadores e visualizações. A fonte e o contexto dos dados deverão ser descritos antes de apresentar resultados.

### Análise de clientes

Possível estudo de segmentação e comportamento de clientes, usando dados cuja origem e permissões de uso sejam documentadas.

### Dashboards

Painéis que apresentem indicadores com contexto, metodologia e limitações claramente descritos.

## Princípios de documentação

Cada projeto incluído futuramente deve informar:

- objetivo e perguntas de análise;
- origem e licença dos dados;
- ferramentas realmente usadas;
- etapas de preparação e análise;
- resultados observados, sem estimativas inventadas;
- limitações e próximos passos.

## Status

Repositório em fase inicial. Nenhuma análise de vendas, análise de clientes, dashboard ou projeto LeadHunter está incluído aqui no momento.
